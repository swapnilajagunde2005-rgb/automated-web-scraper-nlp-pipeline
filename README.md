# Automated Web Scraper & NLP Pipeline

An automated web scraper and Natural Language Processing (NLP) application built with Python and Streamlit.

## Setup and Installation
Option A : 

1. Clone the repository:
   git clone [https://github.com/swapnilajagunde2005-rgb/automated-web-scraper-nlp-pipeline.git](https://github.com/swapnilajagunde2005-rgb/automated-web-scraper-nlp-pipeline.git)
   cd automated-web-scraper-nlp-pipeline

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   streamlit run app.py

   Option B :
   You can directly run this Automated web     scraper by clicking this Streamlit app      link
    Streamlit: https://automated-web-scraper-nlp-pipeline-cxfwc5wc8gbmu88j6wj2ie.streamlit.app/
